# 专业版与购买说明

[English](PRO.en.md) · [返回首页](../README.md)

基础版和专业版是同一个 APK。基础功能可免费使用；专业版增加照片识物、票据辅助录入、收纳标签制作和高级统计与整理清单。

当前价格：**人民币 ¥9.9，一次购买，仅限一台设备**。不自动续费，不含云存储或多设备同步。应用中的“支持作者”入口用于购买本页列出的专业功能，不是单独的打赏。

## 如何购买和激活

1. 在安卓应用中打开“我 → 专业版权益”，查看功能及购买说明。
2. 复制当前手机的完整设备码（`STA1-` 开头）。请勿用网页测试码购买。
3. 按应用内说明核对收款人、付款方式和人民币金额。遇到收款信息不符、无法使用现有付款方式或其他疑问时，先邮件联系，不要付款给陌生账户。
4. 将设备码和付款订单号发到 **zhiandzhi@gmail.com**。可使用应用里的“复制购买信息”再补全订单号。
5. 作者人工核实到账后，通过邮件发送兑换码。兑换码需等待人工处理，不会在付款后自动生成。
6. 在原手机输入或粘贴完整的 `STASH1.` 开头兑换码，点激活；成功后会明确提示。请自行保留邮件和兑换码。

已付款但未收到兑换码，请邮件联系，**不要重复付款**。购买及订单资料不要发在公开 Issues。当前支持方式为应用内提供的微信、支付宝与邮件沟通，不提供外币或银行卡在线结算；海外用户无法付款时请先联系确认可行方式。

## 一台设备是什么意思

兑换码与签发时的设备码匹配。复制到另一台手机不能激活；恢复物品备份也不会转移专业版权益。同一设备码可以重新输入原兑换码；换机、刷机、恢复出厂设置或设备码改变时，请提供原购买记录联系作者核对处理，不承诺自动迁移或免费换机次数。

激活无需注册账号，验证在本机完成。完整物品备份不包含授权凭证，因此请另外保留兑换码邮件。
