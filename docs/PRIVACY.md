# 隐私说明

适用版本：Android 0.4.4-pro-preview。更新日期：2026年10月21日。

[English](PRIVACY.en.md) · [返回首页](../README.md)

## 物品资料保存在本机

物品名称、照片、票据识别内容、位置、分类、标签、备注、草稿和偏好保存在当前设备。当前版本没有账号系统、作者运营的云存储、广告或使用分析服务，不自动向作者上传你的档案。照片识物和票据识别使用随应用提供的本地引擎与模型，在设备上处理。

你主动导出、打印、分享文件或通过邮件提供资料时，文件会交给你选择的系统功能或服务。这些行为不属于自动云同步。不要把备份、原始票据或包含敏感位置的截图发到公开渠道。

## 照片、文件与剪贴板

拍照通过系统相机，选图和备份保存通过系统选择界面。由你选择提供或保存的文件；应用没有要求电话、联系人、位置定位或整库照片读取权限。填写的“存放位置”是你的手动记录，不是手机定位。

点击复制设备码、邮箱或购买信息时，应用向系统剪贴板写入对应内容。粘贴兑换码由你主动操作，不扫描其他应用的剪贴板历史。剪贴板内容应按你的手机环境妥善处理。

## 设备授权

Android 专业版使用系统提供的作用域 Android ID，在设备上散列生成以 `STA1-` 开头的设备码。应用不读取 IMEI 或 MAC，也不申请电话权限。兑换码和授权状态保存在本机；激活时在本机核对签名与设备码，不需要作者服务器。

使用免费基础功能时，无需把设备码发给作者。购买或申请授权帮助时，你会主动通过邮件提供设备码，作者据此签发与该设备匹配的兑换码。设备码不是物品档案，但不建议公开张贴。

## 购买、邮件与反馈

付款由你选择的微信或支付宝服务处理。当前应用不自动获知到账，也不读取你的支付账户密码、银行卡资料或支付应用记录。购买时，请按应用说明向 **zhiandzhi@gmail.com** 提供设备码和付款订单号；不需要发送支付密码或完整物品备份。

作者会使用你主动提供的邮箱、设备码、订单信息及问题描述，核对付款、发送兑换码和处理支持请求。邮件、支付服务和 GitHub 各自处理你在其服务中提交的信息；请同时留意这些服务的隐私设置。不要在公开 Issues 提交设备码、兑换码、订单号或个人照片。

如需询问或请求处理你通过邮件提供的资料，请联系上述邮箱；当前没有自动账户删除或在线订单管理入口。

## 删除与备份

你可以在应用内删除物品；清除应用数据或卸载会删除本机档案和本地偏好。你另行保存的备份、导出文件、照片副本和发出的邮件不会因此自动删除，需要自行管理。

备份包含可读取的物品资料与照片，应用当前不对备份文件提供密码加密。请保存在你信任的位置；如果自行存入网盘，由你选择的网盘服务处理该文件。完整物品备份不含专业版授权，也不含未完成草稿。
