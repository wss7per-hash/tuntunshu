# Pro and purchasing

[简体中文](PRO.md) · [Home](../README.en.md)

Free and Pro use the same APK. Pro adds photo suggestions, receipt assistance, storage label creation, and advanced insights and lists.

Current price: **CNY ¥9.9, one-time purchase for one device**. No automatic renewal, cloud storage, or multi-device synchronization. The “Support the author” entry purchases the Pro features listed on this page; it is not a separate donation.

## Purchase and activate

1. In the Android app, open Me → Pro features and read the feature and purchase details.
2. Copy this phone's complete device code, beginning with `STA1-`. Do not purchase using a browser test code.
3. Check the payee, method, and CNY amount shown in the app. If anything differs or the available methods do not work for you, email first rather than paying an unfamiliar account.
4. Email the device code and payment order number to **zhiandzhi@gmail.com**. The app can copy purchase information for you; add the actual order number before sending.
5. The author checks the payment manually and emails an activation code. Please allow time for manual processing; a code is not generated automatically after payment.
6. Enter or paste the complete code beginning with `STASH1.` on the original phone and activate. The app displays a clear result. Keep the email and code separately.

If you have paid but have not received a code, email the author and **do not pay again**. Do not post order details in public Issues. Current options are the WeChat/Alipay instructions in the app and email support, with no foreign-currency or online card checkout. International users who cannot use these methods should contact the author before paying.

## One-device activation

An activation code matches the device code used when it was issued. It does not activate another phone, and restoring an item backup does not transfer Pro. You can re-enter the original code if the device code remains the same. Contact the author with the original purchase record before changing phones, flashing a ROM, performing a factory reset, or if the device code changes. Automatic transfer or a set number of free device replacements is not promised.

No account is required; activation is checked locally. Item backups do not contain the activation credential, so keep your activation email separately.
