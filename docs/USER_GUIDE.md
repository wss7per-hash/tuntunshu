# 使用指南

[English](USER_GUIDE.en.md) · [返回首页](../README.md)

## 先记一件

点底部“记一件”，先填名称。照片与其他资料可以选填；展开“补充物品资料”记录位置、日期、价格、分类、标签和备注。分类可以自定义。

没有填完时，退出可保留草稿或丢弃；再次录入时可继续草稿。草稿尚未加入正式物品档案，也不包含在完整物品备份中。正式保存后，“再记一件”可选择沿用上一件的位置和分类。

## 查找与整理

在搜索页输入名称、位置或标签，按分类与状态筛选。详情里点击位置、分类或标签可以继续找相关物品。

在首页或搜索结果长按物品进入多选，也可以点“多选”。确认操作对象后批量移动、喜欢或改状态。向右滑进入删除确认；不要把它当成可撤销的归档操作。物品不再拥有时，可以标记“已离手”保留记录；永久删除前请先确认备份。

照片可放大、切换、调整封面和顺序。替换或移除前请查看提示；移除唯一照片后会显示无照片，物品资料仍保留。

## 位置、收纳箱与二维码

在“我 → 位置与收纳箱”管理位置；箱内支持多选移动。已有标签可以免费扫描，但要在本机拥有对应位置资料。二维码不是云端公开清单，也不会把箱内资料分享给任何扫描者。换设备后先恢复同一份备份，才能找到对应资料。

## 备份与恢复

1. 打开“我 → 导出备份”，等系统保存流程完成。
2. 确认文件真的存在，并另存到你信任的位置。仅出现下载或保存窗口，不代表文件已保存。
3. “从备份恢复”先查看内容，再选择保留现有记录、替换或另存副本；确认后才应用。
4. 替换会覆盖对应物品的资料与照片，操作前另外备份当前档案。

完整备份含物品资料、照片、分类、位置和收纳标签标识，不含未保存草稿或专业版授权。CSV、打印和统计报表不能替代完整备份。备份是可读取的文件，当前未提供备份文件密码加密；请妥善保管，不要公开上传。

## 已知限制

- 当前仅提供 Android APK，无 iOS 版本；没有账户、自动云备份或多设备自动同步。
- 金额按人民币记录，切换英文不会换算货币或翻译用户自己的物品资料。
- 离线识别可能出错，运行速度受手机和照片影响；失败时可继续手动填写。
- 清除数据、卸载、手机丢失或损坏可能造成资料丢失，请定期导出备份。
- 专业版绑定一台设备，不能随物品备份转移。换机、刷机或恢复出厂设置前，请先联系作者确认授权处理方式。
- 部分旧系统可能需要更新 Android System WebView。具体问题请附版本及复现步骤反馈，不要在公开 Issues 上传完整备份。
